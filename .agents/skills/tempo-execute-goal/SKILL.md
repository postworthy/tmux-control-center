# Tempo Execute Goal

Drive the active repository goal toward its real outcome, not merely toward a
green narrow test.

## Orient

1. Run repository preflight and the available goal-status command
   (`pnpm goal:status` in Tempo's default starter profile).
2. Read `CONSTITUTION.md`, `SPEC.md`, the selected goal, its current proposal,
   and only the procedure needed for the next unit.
3. Reconcile the goal with the worktree and recent commits. Repository evidence
   overrides stale narrative.

## Loop

1. Select the recorded next action or smallest valuable unmet criterion.
2. Confirm scope, current risk, Authority Envelope, exit condition, and rollback.
3. Act through the smallest coherent reversible change.
4. Observe actual behavior with tools or environmental evidence.
5. Evaluate the result against the criterion—not against effort or intent.
6. Repair when the cause changes and retry bounds permit; otherwise follow the
   recovery rules.
7. Checkpoint criterion evidence, progress, discoveries, decisions, retry state,
   outcomes, and exactly one next action.
8. Continue automatically while authority remains valid.

Read [loop-and-recovery.md](references/loop-and-recovery.md) when a check fails,
the goal may be stale, or a pause/block/completion decision is unclear.

## Pause and Complete

Pause at every boundary in the goal and Constitution. Do not treat difficulty,
elapsed time, or a context boundary as failure. Do not declare completion until
all criteria have final evidence, canonical verification passes, documentation
matches behavior, required review exists, and no required work remains.
